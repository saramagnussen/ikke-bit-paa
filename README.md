# Ikke bit på

Et interaktivt nettkurs om phishing for ansatte på legekontor som håndterer sensitiv pasientinformasjon.

Prosjekt i DCST1002 Teamwork og cybersikkerhet, NTNU – Gruppe 2.

## Innhold

- **Introkurs** i fire moduler: hva phishing er, hvorfor legekontoret er et mål, varselsignaler og hvordan man reagerer
- **Innboks-øvelse** der man finner varselsignaler i fiktive e-poster
- **Quiz** med åtte spørsmål (7 riktige for å bestå)
- **Oppfølgingsplan** med simulerte phishing-tester fra ledelsen

## Gruppe

Emil S. Alm · Endre Nøtland · Sara Magnussen · Oleksander

Alle e-poster, avsendere og legekontor på siden er fiktive.
